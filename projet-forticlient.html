Fiche projet

Création d’un tutoriel vidéo VPN FortiClient

Un support pédagogique conçu pour faciliter l’installation d’un accès VPN par les collaborateurs.

← Retour aux réalisations
01 / Contexte

Pourquoi ce travail ?

Un besoin d’accompagnement des collaborateurs à distance lors de l’installation du client VPN FortiClient a motivé la création d’une ressource explicative.

02 / Démarche

Comment j’ai procédé

  • Préparer les éléments visuels et les supports de présentation avec Canva.
  • Enregistrer les étapes d’installation réalisées sous Windows.
  • Assembler et monter les séquences avec Adobe Premiere Pro.
03 / Retour d’expérience

Ce que cette réalisation illustre

Le résultat décrit dans le dossier est un tutoriel vidéo réutilisable par l’équipe de support informatique, afin de guider les utilisateurs dans les étapes d’installation.

04 / Dossier de preuves

Pièces à compléter

Ajouter une capture du tutoriel, un extrait autorisé ou une version expurgée des informations internes, et expliciter les retours éventuels des utilisateurs.
