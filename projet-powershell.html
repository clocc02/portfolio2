Automatisation de la configuration DNS en PowerShell

Une approche par script pour réinitialiser l’adresse des serveurs DNS d’une carte réseau active.

← Retour aux réalisations
01 / Contexte

Pourquoi ce travail ?

Le portfolio de départ présente un script PowerShell visant à passer d’une configuration DNS fixe à l’obtention automatique des serveurs DNS sur une interface réseau.

02 / Démarche

Comment j’ai procédé

  • Identifier une interface réseau active avec Get-NetAdapter.
  • Récupérer l’index de cette interface.
  • Réinitialiser les serveurs DNS configurés manuellement avec Set-DnsClientServerAddress.

Extrait PowerShell commenté

Exemple pédagogique simplifié inspiré de l’extrait du dossier, corrigé sur la syntaxe de filtrage. Il cible la première carte active détectée.

# Sélection d’une interface réseau active
$interface = Get-NetAdapter |
    Where-Object { $_.Status -eq 'Up' } |
    Select-Object -First 1

# Retour aux serveurs DNS automatiques
if ($interface) {
    Set-DnsClientServerAddress `
        -InterfaceIndex $interface.ifIndex `
        -ResetServerAddresses
}
Précaution : cette modification nécessite généralement des droits administrateur. Dans un contexte réel, il faut choisir explicitement la bonne interface et vérifier le résultat.
03 / Retour d’expérience

Ce que cette réalisation illustre

Cette démarche illustre l’intérêt de l’automatisation pour des opérations de configuration répétitives. L’extrait présenté ci-dessous est une version pédagogique simplifiée, à adapter et tester avant utilisation réelle.

Pièces à compléter
