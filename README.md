# Portfolio BTS SIO SISR — Ilan Breton

Site multipage statique HTML/CSS/JavaScript. Le dossier s’ouvre directement dans un navigateur, sans installation ni serveur.

## Démarrer

1. Décompresser le ZIP en conservant tous les sous-dossiers.
2. Ouvrir `index.html` dans Chrome, Firefox ou Edge.
3. Utiliser le bouton soleil/lune pour passer d’un thème à l’autre ; le choix est mémorisé.
4. Naviguer vers **Documents** pour lire ou télécharger les PDF et vers **Stage** pour les photos du rapport.

## Contenu

- Pages principales : `index.html`, `a-propos.html`, `projets.html`, `stage.html`, `veille.html`, `competences.html`, `contact.html`, `documents.html`.
- Projets : pfSense, topologie LAN/DMZ, Active Directory, IPv4, Bootstrap 5.3, SQL, PowerShell, FortiClient, KACE, maintenance, support.
- PDF originaux : `assets/documents/CV_2026-10-05_Ilan_Breton.pdf` et `assets/documents/RAPPORT-DE-STAGE.pdf`.
- Photos du rapport : `assets/img/stage/` (sélection en WebP, légendée sur le site).
- Style et thèmes : `assets/css/style.css`.
- Navigation, filtres et thème : `assets/js/main.js`.

## Quelques précautions avant publication publique

- Le **CV original** contient des coordonnées personnelles (adresse postale et téléphone).
- Le **rapport original** peut contenir des captures, noms de collaborateurs, organigrammes ou informations d’entreprise. Vérifier leur confidentialité et l’autorisation de diffusion avant de mettre ce dossier en ligne.
- Les photographies intégrées au site évitent les vues détaillées de tableaux internes et de comptes nominatifs, mais vérifier malgré tout qu’aucune donnée sensible n’apparaît.
- Les fiches des cours de 1re et 2e année sont basées sur les travaux mentionnés dans ton dossier et les informations de ton parcours. Il reste à joindre les vrais sujets, captures et codes sources pour en faire des preuves détaillées E5.

Le guide **OU_MODIFIER_MON_PORTFOLIO.md** indique précisément où ajouter tes nouvelles preuves.
