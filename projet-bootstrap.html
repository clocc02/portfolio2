Intégration d’une interface web Bootstrap 5.3

Travail de création et de mise en page d’une interface avec les composants et la grille responsive de Bootstrap 5.3.

← Retour aux projets

Contexte

Cet atelier associe la découverte du développement web aux compétences transversales de mise à disposition d’un service informatique.

Démarche et éléments travaillés

  • Structurer une page avec HTML sémantique.
  • Utiliser les classes Bootstrap pour mettre en page une interface responsive.
  • Tester le rendu sur différentes tailles d’écran.
  • Comprendre les liens entre HTML, CSS, composants et accessibilité.

Compétences mobilisées

Intégration HTML/CSS, responsive design et présentation d’un service web.
